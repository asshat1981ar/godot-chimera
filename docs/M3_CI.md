# M3 CI / Build Pipeline

**Owner:** SYS (code-analyst) · **Version:** 0.3.0

This document describes the GitHub Actions workflow (`.github/workflows/godot.yml`) and the local Android export setup used for the Chimera: Ashes of the Hollow King Godot 4 project.

## Local quick commands

```bash
# Full validation gate used by M3-12
bash scripts/tests/run_all_checks.sh

# Headless simulation tests only
bash run.sh --headless --path . res://scenes/tests/simulation_tests.tscn

# Export a signed debug APK locally
bash export_apk.sh /tmp/chimera-debug.apk
```

## GitHub Actions workflow

File: `.github/workflows/godot.yml`

### Triggers

- `push` to `main` or `master`
- `pull_request` targeting `main` or `master`

### Jobs

1. **Install Godot** — downloads the official `Godot_v4.2.2-stable_linux.x86_64` binary.
2. **Static GDScript check** — runs `scripts/tests/validate_gdscript.py`.
3. **Validate JSON data** — validates every `data/*.json` file with Python's `json.tool`.
4. **Headless project import** — ensures the project imports cleanly.
5. **Headless simulation tests** — runs `res://scenes/tests/simulation_tests.tscn`.
6. **Export Android APK** — uses `export_apk.sh` and signs the APK.
7. **Verify APK** — confirms `aapt dump badging` and `apksigner verify` pass.
8. **Upload APK artifact** — stores the APK as `chimera-android-apk`.

### Required repository secrets (for release signing)

If you want CI to sign with a real release keystore, add these secrets in the GitHub repository settings:

| Secret name | Value |
|---|---|
| `GODOT_ANDROID_KEYSTORE` | Base64-encoded release `.keystore` / `.jks` file |
| `GODOT_ANDROID_KEYSTORE_ALIAS` | Key alias |
| `GODOT_ANDROID_KEYSTORE_PASSWORD` | Keystore password |

If the secrets are absent, CI falls back to the repository debug keystore generated by `export_apk.sh`. This keeps PRs from external forks harmless but still produces an installable APK.

### Runner expectations

The workflow assumes the `ubuntu-latest` runner has the Android command-line tools installed under `/usr/local/lib/android/sdk` (GitHub-hosted runners include this by default). Local or self-hosted runners should set the `ANDROID_SDK_BUILD_TOOLS` and `ANDROID_SDK_PLATFORM_TOOLS` environment variables to the correct paths.

## Export configuration

- `project.godot`: version is `0.3.0`.
- `export_presets.cfg`: Android preset version code `3`, version name `0.3.0`; debug symbols disabled (`gradle_build/use_gradle_build=false`).
- `export_apk.sh`: generates a debug keystore at `.tools/keystore/chimera-debug.keystore` if none exists and patches the export preset to use it for local exports.

## Expected badging output

```
package: name='com.chimera.ashesofthehollowking' versionCode='3' versionName='0.3.0' ...
```

## Notes

- The workflow does **not** publish to Google Play; it only builds and verifies the APK.
- Release builds should switch to `--export-release` in `export_apk.sh` when a real release keystore is configured.
- The debug keystore is safe to commit or leave in the workspace because it is only used for debug QA builds.
