# Chimera: Godot 2.5D Overhead Port

This directory contains a complete, runnable Godot 4 project that re-implements the **Chimera: Ashes of the Hollow King** experience as a 2.5D overhead exploration game with a parchment/gothic UI, procedural placeholder sprites, and a deterministic simulation layer.

## What was ported

### Core architecture
- **`scripts/core/game_state.gd`** — canonical save-state (act, current node, party, inventory, completed scenes, dispositions, journal, settings).
- **`scripts/core/event_bus.gd`** — observable event bus decoupling UI from simulation.
- **`scripts/core/simulation.gd`** — deterministic engine handling travel, scene resolution, disposition feedback loops, stance-duel combat, and camp risk.
- **`scripts/core/content.gd`** — loads the existing authored JSON data (`npcs.json`, map JSON, scene JSON, etc.) into Godot dictionaries.
- **`scripts/core/scene_switcher.gd`** — global scene transition manager with a stashed payload.

### 2.5D overhead world
- **`scenes/screens/overhead_map.tscn`** + **`scripts/world/overhead_map.gd`** — builds the act map from JSON, draws parchment terrain tiles, connects nodes with `Line2D`, and spawns interactive node tokens and ambient NPC tokens.
- **`scenes/world/map_node_token.tscn`** + `map_node_token.gd` — clickable map nodes that switch state (active/neutral/completed/blocked) and open dialogue when the attached scene has an NPC.
- **`scenes/world/npc_token.tscn`** + `npc_token.gd` — wandering tokens near their home node, tinted by disposition.
- **`scripts/world/map_camera.gd`** — pan (WASD / drag) and zoom (scroll) camera with clamps.

### UI / UX
- **`scenes/screens/main_menu.tscn`** — New Game, Continue, Settings, Quit.
- **`scenes/screens/dialogue_screen.tscn`** — portrait + ink-wash dialogue bubble + disposition bar.
- **`scenes/screens/camp_screen.tscn`** — rest screen with risk summary.
- **`scenes/screens/party_screen.tscn`** — recruit/remove companions.
- **`scenes/screens/journal_screen.tscn`** — records completed scenes and entries.
- **`scenes/screens/settings_screen.tscn`** — music, SFX, reduced motion, cloud AI toggle, text speed.
- **`assets/ui_theme.tres`** — shared parchment/gothic theme.
- **`assets/shaders/ink_wash.gdshader`** — optional ink-wash shader for parchment surfaces.

### Sprites
All placeholder art was generated by **`scripts/generate_placeholder_sprites.py`** using ImageMagick:
- App icon (`assets/images/ui/app_icon.png`)
- Terrain tiles (`assets/images/map_tiles/`)
- Map node markers (`assets/images/map/`)
- NPC portraits and tokens (`assets/images/npcs/portraits/`, `assets/images/npcs/tokens/`)
- Item icons (`assets/images/items/`)
- Combat stance poses (`assets/images/combat/`)
- UI frames (`assets/images/ui/`)

Run the generator again after adding new NPCs:
```bash
python3 scripts/generate_placeholder_sprites.py
```

## How to run

1. Install [Godot Engine 4.2+](https://godotengine.org/download).
2. Open the project by selecting the `godot-chimera` folder (or `godot-chimera/project.godot`).
3. The main scene is `scenes/screens/main_menu.tscn`.
4. Press **F5** (or the Play button) to run.

## Input

| Action | Control |
|---|---|
| Pan map | WASD or middle-mouse drag |
| Zoom | Mouse wheel |
| Select node | Left click |
| Back / menu | Escape or Q |

## Migration notes from the Android/Kotlin codebase

- **Data**: all authored JSON files from `app/src/main/assets/` are copied into `data/` and loaded at runtime. No manual conversion is required.
- **Simulation**: the deterministic rules from `chimera-core` are re-implemented in GDScript. The Android Kotlin `DuelEngine`, `RelationshipArchetypeEngine`, and `DispositionTracker` equivalents live in `simulation.gd`.
- **State**: `GameState` replaces the Android save-state serialization; `save_game()` writes `user://chimera_save.json`.
- **Events**: `EventBus` mirrors `com.chimera.core.events.GameEventBus`.
- **Portraits / sprites**: the original Android manifest-based sprite system is not used. Instead, sprites are generated by path convention (`portrait_<npc_id>.png`, `token_<npc_id>.png`).
